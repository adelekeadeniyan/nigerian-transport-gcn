# Nigerian Transport Network Graph Neural Network

This repository houses spatial graph neural network pipelines designed for regional infrastructure analysis across Nigerian transport networks.

## Architecture
The system constructs spatial coordinate graphs from point geometry features and processes structural topology using multi-layer graph convolutions.

## Data Attribution
This project relies on geospatial data from the African Transport Systems Database.

Colombo, S., Pant, R., Young, M., Thomas, F., Russell, T., Verschuur, J., & Hall, J. W. (2025). The African Transport Systems Database - a geospatial database of multi-modal connected networks [Dataset]. Zenodo. https://doi.org/10.5281/zenodo.17861120
